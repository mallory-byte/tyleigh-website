First time here? Get your one-time access key (about 2 minutes)
  1. Open this GitHub page (sign in if it asks).
  2. Token name: Wallace editor. Expiration: pick whatever you like (e.g. 1 year).
  3. Under Repository access: choose Only select repositories → pick wallace-family-farms.
  4. Under Permissions → Repository permissions → Contents: set it to Read and write.
  5. Click Generate token, copy it, and paste it in the box below.

Your key is saved only in this browser and only talks to GitHub. Treat it like a password — keep this page to yourself and don't use it on a shared computer.
